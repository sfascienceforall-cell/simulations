Configuration électronique et nombres quantiques

Remplis les cases quantiques électron par électron : Klechkowski, Pauli et Hund, puis les ions et les exceptions.

Élément
Z
Charge
Exemples

Ordre de Klechkowski

On suit les flèches : n + l croissant, puis n croissant à n + l égal. C'est une règle empirique (un modèle).

Cases quantiques

Clique sur une case pour lire ses quatre nombres quantiques. Convention de la simulation : les cases vont de mℓ = −l (à gauche) à mℓ = +l, et le premier électron d'une case a ms = +½ (flèche ↑). D'autres cours prennent l'ordre inverse : seule compte la règle (spins parallèles avant d'apparier). La simulation écrit une configuration ; elle ne dit pas si l'ion existe (Na²⁺ ou He⁻, par exemple, n'existent pas dans les conditions usuelles).

Quatre nombres décrivent un électron : n (couche, n = 1, 2, 3…), l (sous-couche, 0 ≤ l ≤ n − 1), mℓ (orbitale, −l ≤ mℓ ≤ +l) et ms (spin, +½ ou −½).
Principe de Pauli : deux électrons d'un même atome n'ont jamais les quatre mêmes nombres, donc 2 électrons au plus par case.

Teste un quadruplet

Ce qu'il faut retenir

  • Une case = une orbitale = un trio (n, l, mℓ). Elle contient au plus 2 électrons de spins opposés (Pauli).
  • Nombre d'orbitales : s 1, p 3, d 5, f 7. Électrons au maximum : 2, 6, 10, 14. Une couche n contient n² orbitales et au plus 2n² électrons.
  • Klechkowski : on remplit par n + l croissant, puis n croissant (4s avant 3d, 6s avant 4f).
  • Hund : dans une sous-couche, on occupe d'abord toutes les cases avec des spins parallèles, puis on apparie.
  • Cr, Mo : (n−1)d⁵ ns¹ ; Cu, Ag, Au : (n−1)d¹⁰ ns¹. Ce sont les exceptions à connaître.

Pièges classiques

  • Fe²⁺ n'est pas [Ar] 4s² 3d⁴ : un cation de transition perd d'abord ses électrons ns. Fe²⁺ = [Ar] 3d⁶.
  • Apparier trop tôt : en 2p⁴ (oxygène), il reste 2 électrons célibataires, pas 0.
  • Confondre l'ordre de remplissage et l'ordre d'écriture : [Ar] 4s² 3d⁶ et [Ar] 3d⁶ 4s² décrivent le même atome.
  • Oublier que l ne peut pas valoir n : il n'existe ni 1p, ni 2d, ni 3f.

Défis

Combien d'électrons célibataires dans Fe, puis dans Fe³⁺ ?
Fe : 3d⁶ → 4 célibataires (une case appariée, quatre cases à un électron). Fe³⁺ = [Ar] 3d⁵ → 5 célibataires : chaque case d contient un électron. Vérifie avec le compteur sous la formule.
Quel cation de charge 3+ a exactement la même configuration que Mn²⁺ ?
Mn²⁺ = [Ar] 3d⁵ (23 électrons). Il faut Z − 3 = 23, donc Z = 26 : Fe³⁺ = [Ar] 3d⁵.
Donne les quatre nombres quantiques du 8ᵉ électron de l'oxygène (convention de la simulation).
Le 8ᵉ électron est le 4ᵉ de 2p : les trois premières cases ont chacune un ↑, le 4ᵉ s'apparie dans la première case. n = 2, l = 1, mℓ = −1, ms = −½. Avec la convention inverse, on trouverait mℓ = +1 : vérifie toujours la convention de ton cours.
